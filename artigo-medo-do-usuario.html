Medo do Usuário

O Usuário mais louco que tem, o usuário de crack? não, tem um mais nóia. O usuário da interface chamada política. Durante muito tempo tive medo de fãs e extremistas. De marcas, bandas, religiosos, nacionalistas, armamentistas, usuários da Apple, enfim, qualquer extremista chato que tenha transformado uma preferência em verdade absoluta. Mas isso era pouco. Agora apareceu um tipo de usuário que me assusta muito mais: o usuário político. Aquele que não apenas utiliza a interface, mas transforma a interface em ídolo, religião, torcida organizada e, se necessário, arma contra qualquer outro usuário que pense diferente.

Tratando a política como uma interface e o povo como usuário, a coisa fica ainda mais estranha. O usuário vota para escolher qual interface vai representá-lo. E, embora existam várias opções, duas parecem ocupar praticamente toda a tela. A Interface A e a Interface B. Existem outras, claro, mas aparentemente não possuem fãs suficientes para entrar na lista principal. Então o usuário fica diante de duas opções: a interface que te afoga ou a interface que te sufoca. E ainda existe uma terceira opção, que aparentemente é considerada um defeito de sistema: não escolher nenhuma delas.

A Interface A está há anos no ar. É pesada, capenga, consome memória RAM do usuário, ocupa espaço no HD com arquivos que ninguém pediu e passa por atualizações que frequentemente parecem mais uma regressão do que uma melhoria. É uma interface onde aparecem escândalos, contradições, promessas, roubalheiras, festas, discursos e mais discursos, enquanto o usuário continua ali, olhando para a tela como se estivesse tudo funcionando perfeitamente. O usuário da Interface A geralmente tem uma habilidade impressionante: consegue enxergar todos os problemas da Interface B, mas desenvolve uma cegueira seletiva quando o problema aparece na própria interface. É o famoso “tudo bem, mas olha o outro”. Como todo bom fã, ele não precisa que sua interface seja boa. Basta que ele acredite que a outra seja pior.

Nesse meio-tempo, os usuários da Interface A se cansaram e decidiram trocar de sistema. Votaram na Interface B, que entrou prometendo mudança, renovação e uma nova experiência de usuário. Durante quatro anos, porém, a nova interface acumulou seus próprios bugs. A linguagem ficou mais chula, banal e agressiva, quase uma interface em modo de guerra. Em momentos de crise, a experiência não entregou aquilo que os usuários precisavam. Algumas funcionalidades não foram atualizadas, outras simplesmente não apareceram e, quando alguém perguntava pelo funcionamento do sistema, a resposta frequentemente apontava para a interface anterior: “Olha o que eles fizeram”, “olha o que deixaram”, “a culpa é deles”. É curioso: depois de quatro anos no ar, continuar apontando para a interface anterior sempre que alguma coisa dava errado deixou de parecer uma justificativa e passou a funcionar quase como uma funcionalidade nativa do sistema.

E o usuário da Interface B também é um caso à parte. É aquele que consegue transformar fake news em notícia, corrente de WhatsApp em banco de dados e teoria absurda em informação confidencial. É capaz de desconfiar de qualquer instituição que apresente uma informação contrária àquilo em que acredita, mas aceitar imediatamente qualquer história que confirme sua visão de mundo. Pode falar em Deus enquanto deseja a destruição do adversário, falar em família enquanto defende comportamentos que contradizem aquilo que diz proteger e falar em honestidade enquanto trata denúncias contra sua própria interface como perseguição. Pode até exigir voto impresso porque não confia no banco de dados, mas confiar cegamente naquilo que recebeu em um grupo de mensagens. A lógica é maravilhosa: “Não acredito nos dados, mas acredito no áudio que meu primo recebeu.”

E então existe o usuário que não escolhe nenhuma das duas interfaces. Esse talvez seja o usuário mais curioso de todos. Ele olha para A, olha para B e pensa: “Não quero nenhuma.” Só que aí vem a parte mais interessante: os usuários das duas interfaces começam a dizer que a culpa é dele. Se A ganhar, a culpa é dele. Se B ganhar, a culpa também é dele. Se ele não quer nenhuma das duas, aparentemente é obrigado a escolher uma delas para não ser acusado de favorecer a outra. É como se o sistema não aceitasse a opção “não gostei de nenhuma”. E essa é justamente a parte que me incomoda: a obrigação de escolher entre duas coisas que você considera ruins e ainda ser tratado como culpado por não querer participar da disputa.

Eu escolho não escolher. Não porque ache que política não importa, mas justamente porque não tenho interesse em transformar político em ídolo. Voto nulo, sim. Não quero escolher entre morrer afogado ou sufocado. E muito menos quero entrar nas fogueiras criadas pelos usuários das duas interfaces. A fogueira das verdades absolutas, dos “nós contra eles”, das teorias, das mentiras, das execuções comemoradas, do caos defendido como solução e, principalmente, da utilização do nome de Deus para justificar coisas que deveriam fazer qualquer pessoa parar e pensar.

O que mais me assusta não é o político. É o usuário. O político é profissional em mentir, prometer, mudar de discurso, cometer erros e até desaparecer da tela. O usuário continua ali. Clicando. Compartilhando. Defendendo. Brigando. Criando ídolos. E esse é o verdadeiro bug dessa merda de interface: o usuário deixou de utilizar a política e passou a acreditar nela.

E o pior é ser tratado como ignorante simplesmente porque você discorda desses usuários. Em especial pelo usuário da Interface B, que neste momento está órfão da interface para idolatrar. Ele olha com uma certa superioridade para quem não quer nem chegar perto da interface que ele escolheu, como se a recusa fosse sinal de burrice e não uma escolha consciente. Para ele, não querer a Interface B significa não entender política, não ter consciência ou, pior ainda, estar ajudando a Interface A. Só que talvez ele não consiga compreender uma coisa bastante simples: eu posso olhar para a Interface A, olhar para a Interface B, enxergar o histórico, os bugs, o caos, a miséria, as contradições e simplesmente concluir que não quero instalar nenhuma das duas. Não preciso escolher entre afundar e sufocar só porque os dois lados decidiram que essas são as únicas opções possíveis. Afinal, se política é uma interface criada para servir ao usuário, talvez esteja na hora de lembrar uma regra básica de UX: quando o usuário precisa escolher entre duas experiências ruins a interface é uma merda.

E para deixar essa experiência de usuário ainda mais assustadora, basta olhar para a Argentina. No segundo semestre de 2025, 28,2% da população estava abaixo da linha da pobreza. No primeiro semestre de 2026, esse número subiu para 32,3% ou seja???? um aumento de 4,1 pontos percentuais, ou 14,5% em termos relativos. Não é exatamente o tipo de métrica que você colocaria em um dashboard de “experiência do usuário” para comemorar. E o mais curioso é que, mesmo diante de uma realidade cheia de contradições, a nossa própria Interface B encontrou motivos para elogiar o trabalho realizado por lá. É nesse momento que eu começo a ter medo de verdade. Porque quando uma interface começa a admirar os bugs da outra, enquanto os usuários continuam brigando para decidir qual delas é melhor, o problema já não está mais apenas na interface. O verdadeiro bug está no usuário que, de tanto defender sua interface, esqueceu que era ele quem deveria estar sendo atendido por ela. (Eu vi essa pesquisa em um site de notícias que os usuários dessa interface, não acreditam... Portanto para esses usuários "É mentira minha").
